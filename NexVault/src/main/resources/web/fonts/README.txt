NexVault typefaces
==================
Urbanist-400/500/600.woff2 and SpaceGrotesk-400/500/600/700.woff2 are downloaded automatically by run-vault.bat
(SIL Open Font License). If you are offline, download them yourself and place them in this folder with exactly those names.

Godber is the logo typeface and is NOT bundled. Place your licensed copy here as one of:
    Godber.woff2   (preferred)   Godber.otf   Godber.ttf
Until then the logo falls back to a serif stack (Cinzel / Trajan / Optima / Georgia). Nothing else changes.
